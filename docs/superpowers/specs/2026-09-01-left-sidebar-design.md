# I 左侧侧栏工作台设计

## 目标

将 Android 主界面改造成类似 ChatGPT 手机版的“左侧侧栏 + 主聊天区”结构。侧栏负责工作入口和最近会话，主区域继续承载现有聊天、终端、文件和其他页面，不改变底层 Agent、模型、沙盒和数据库能力。

## 信息架构

侧栏从上到下固定为：

1. 新会话
2. 手机库
3. 项目
4. 技能
5. 文案
6. 空白分隔
7. 最近
8. 最近使用的会话列表

现有功能映射：

- 新会话：创建会话并关闭侧栏
- 手机库：进入现有文件/存储浏览能力
- 项目：进入现有工作区或项目入口；若当前版本没有独立项目页，先复用工作区入口
- 技能：进入现有 Skills 管理页
- 文案：进入文案专用聊天入口，首版使用新会话并附带文案场景预设
- 最近：复用现有会话列表数据，按最近更新时间倒序展示

## 交互与动画

- 手机默认只显示主内容区，侧栏关闭。
- 点击顶部菜单按钮打开侧栏。
- 从屏幕左边缘向右拖动打开侧栏。
- 侧栏打开后向左拖动或点击遮罩关闭。
- 侧栏宽度为屏幕宽度的约 82%，设置上下限避免小屏或大屏过宽。
- 打开时主内容区向右平移少量距离，不做大幅缩放，保证聊天内容稳定可读。
- 侧栏打开时显示半透明遮罩；点击遮罩关闭侧栏。
- 松手后根据拖动距离和速度吸附到完全打开或完全关闭。
- 返回键优先关闭侧栏，侧栏关闭时保持现有返回行为。
- 点击最近会话后导航到对应聊天，并自动关闭侧栏。
- 切换到终端、文件、设置等页面时保留统一的菜单入口。

## 架构

新增一个 Android Compose 层的 AppShell/侧栏容器，包裹现有 NavHost：

```text
AppShell
├── MainContent / NavHost
├── Scrim
└── Sidebar
    ├── 固定功能入口
    └── 最近会话列表
```

侧栏状态只保存 UI 层的 `Closed` / `Open` 和拖动偏移，不复制会话数据。最近会话继续由现有 Repository/Flow 提供，避免出现两套会话状态。导航回调由 AppShell 接收并交给现有 NavController。

## 兼容性

- 不修改 Room 数据库结构。
- 不修改模型、Agent、Skills、MCP、终端和沙盒接口。
- 不改变已完成的 `com.i.app` 包名和 `I` 品牌重命名。
- 手机使用抽屉模式；横屏或平板可在后续版本固定显示侧栏。
- 触摸拖动不可用时，顶部菜单按钮和返回键仍可完成打开/关闭。

## 验收标准

- Android 手机启动后默认进入主聊天区，侧栏处于关闭状态。
- 点击菜单按钮可以打开左侧侧栏。
- 左边缘右滑可以打开，侧栏左滑可以关闭。
- 侧栏宽度和遮罩符合预期，动画无明显跳闪。
- 新会话、手机库、项目、技能、文案入口均可点击。
- 最近会话显示真实历史数据，点击后能进入正确会话。
- 侧栏关闭后，原有聊天、终端、文件和设置导航继续可用。
- `:app:assembleDebug` 构建通过。
- 现有 JVM 单元测试不回归。
